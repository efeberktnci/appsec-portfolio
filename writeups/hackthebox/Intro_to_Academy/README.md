## Overview

This is the starting module for Hack The Box Academy. It introduces the Academy learning flow, the structure of modules and sections, exercises, workstations, paths, and certifications before moving into technical training.

## Module outline

1. Introduction
2. HTB Academy Structure
3. Modules
4. Sections
5. Exercises
6. Paths and Certifications
7. Getting Help
8. Next Steps

## Learning notes

- Academy modules are divided into smaller sections that combine reading material, examples, and exercises.
- Interactive sections can provide a workstation or an exercise target for authorized practice.
- Paths group related modules into a recommended sequence for a subject area or job role.
- Progressing through this module establishes the workflow that will be used in later Academy writeups.
